# Architecture

Design records for the systems and authority boundaries behind the game.

- [`engineering/citadel/`](../engineering/citadel/README.md) documents the generated city, publication pipeline, and structural proofs.
- [`world-generation/`](../world-generation/README.md) covers terrain, biomes, and underground generation.
- NPC navigation and tutorial-town architecture live under [`gameplay/`](../gameplay/README.md).

These records have different dates and status. Use the game's current `AGENTS.md`, implementation, and tests to determine what is authoritative today.
